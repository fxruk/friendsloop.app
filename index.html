In 3 Schritten losspielen

Keine Registrierung. Kein Download für deine Freunde nötig. Einfach losspielen.

1
🎨

Name & Avatar wählen

Gib deinen Namen ein und wähle aus 24 Emojis deinen persönlichen Avatar. Fertig in 5 Sekunden.

2
🎮

Spiel auswählen & Raum erstellen

Wähle ein Minispiel und erstelle einen Raum. Du erhältst einen 5-stelligen Code — ganz einfach.

3
🚀

Code teilen & spielen

Teile den Code per Nachricht an deine Freunde. Alle treten bei und spielen in Echtzeit — jeder auf dem eigenen Handy.
